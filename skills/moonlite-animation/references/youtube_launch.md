# YouTube launch

## Brand kit (made for "Moonlit Tales"; reusable pattern)
- Channel name: general (not tied to one character) — e.g. "Moonlit Tales"; check the handle is free.
- Logo 800x800 from a painted image the user generates (child reading on a crescent moon); round preview.
- White line-art version of the logo for the video watermark (150x150, transparent, soft dark halo) and the
  credits card. Ask GPT: "Recreate this exact image as a clean, white, single-colour logo… transparent PNG".
- Banner 2560x1440: build from the user's high-res painting; remove elements the logo already shows; put the
  title exactly centred in the 1546x423 phone-safe strip; check a TV/desktop/phone preview. Don't upscale a
  small image 4x (blurry); ask for a 2560x1440 painting with empty sky instead.
- Intro card, end screen background, ornament PNG, channel description and keywords text file.

## Thumbnail
- Big emotional close-up faces (crying child + robot eyes reflecting the mother's photo) + a 3–5 word hook
  ("He Lied — for five years") + a small diagnostic tag ("LIE DETECTED").
- Fonts are personal: render an options sheet (6–8 fonts on the same picture), let the user pick, then match
  their reference images. Keep text away from faces and the bottom-right duration badge.

## Title / description / tags
- The title adds what the thumbnail doesn't say (thumbnail = the shock, title = what the lie was).
- Description: hook paragraph, story setup, chapters (0:00 first, one per chapter + Credits), a family
  discussion question (not "comment below" if made for kids), credit line, honest AI-tools line, 5–7 hashtags.
- Tags and channel keywords: match the actual film (emotional, ages ~5–10), not "toddler sleep stories".

## Upload settings
- Upload Private first; wait for 2160p in the quality menu; then publish or schedule (Fri–Sun, 5–7 pm local).
- Audience: set "made for kids" honestly (legal, COPPA). It disables comments, end screens/cards, the bell and
  personalised ads — adjust the description accordingly.
- Altered content: Yes. Category: Film & Animation. Caption certification: none (never aired on TV).
  Subtitles: upload the .srt "with timing" (burned-in subtitles are fine too; the track helps search).
- Channel trailer: Customisation → Home tab → Add section → Channel trailer (+ Spotlight for subscribers).
- Channel keywords: Settings → Channel → Basic info → Keywords.

## Shorts
- 25–40 s vertical (1080x1920): blurred-zoom background, the 16:9 clip centred, a two-line hook at the top in
  the brand font, logo + "Full story on <channel>" at the bottom; end on a cliffhanger.
- Long video first; Shorts over the next days; Reels aimed at parents of the real age group from the channel's
  own account.
